# Jackett fork with Brazilian indexers (ApacheTorrent, RedeTorrent, HDRTorrent)

This is an **unofficial fork** of [Jackett](https://github.com/Jackett/Jackett). It is **not affiliated with or endorsed by the Jackett project**. Everything outside the three files listed below is upstream Jackett, unchanged. License: GPL-2.0, same as upstream.

## What is different

The branch `br-indexers` is the upstream tag `v0.24.2830` plus three files in `src/Jackett.Common/Indexers/Definitions/`:

| File | What it does |
|---|---|
| `ApacheTorrent.cs` | Indexer for apachetorrents.com. Broken in upstream `v0.24.2830` (see the issue below) and no longer present in upstream `v0.24.2887`. |
| `RedeTorrent.cs` | Indexer for redestorrents.com. Broken in upstream `v0.24.2830` and no longer present in upstream `v0.24.2887`. |
| `HDRTorrent.cs` | Upstream indexer for hdrtorrents.net, with the detail page timeout described below. |

Changes over the upstream versions of these indexers:

- ApacheTorrent and RedeTorrent: parsers rewritten for the current layout of the sites (title, quality, audio language, size, publish date, one result per magnet link).
- A slow or broken detail page no longer kills the whole search. Each detail page has a 15 second limit and, if it fails, only that result is skipped. Before this, one stuck page made the whole search fail after almost three minutes.
- File size: several sizes in one field are read one by one (they used to be glued into an absurd number), and the fallback estimate understands `1080P`, `4K` and `ULTRA HD`.
- `WEB` is no longer turned into `WEB-DL-DL` when the site already says `WEB-DL`.

The upstream issues these changes relate to are [#17066](https://github.com/Jackett/Jackett/issues/17066) (ApacheTorrent), [#17096](https://github.com/Jackett/Jackett/issues/17096) (HDRTorrent) and [#17097](https://github.com/Jackett/Jackett/issues/17097) (RedeTorrent).

## How to use it

Jackett releases a new build almost every day, and this fork does **not** track them. Each release here is a patched `Jackett.Common.dll` built from one specific upstream tag. It only works with that same Jackett version (the release name says which). For any other version, build it yourself (below).

### Docker (tested)

Download `Jackett.Common.dll` from the release and put it next to this `Dockerfile`:

```dockerfile
FROM lscr.io/linuxserver/jackett:v0.24.2830-ls3
COPY Jackett.Common.dll /app/Jackett/Jackett.Common.dll
```

```
docker build -t jackett-br:v0.24.2830 .
```

Then use the image `jackett-br:v0.24.2830` in your compose file instead of `lscr.io/linuxserver/jackett`. Because it is a local image, `docker compose pull` will not update it. To move to a newer Jackett version, rebuild as described below.

Only the Docker image above was tested. The DLL is a managed assembly and may also work in other installs of the exact same Jackett version, but that was not tested.

### Build it yourself (any Jackett version)

1. Download the source of the Jackett tag you run and copy the three `.cs` files from this repository over `src/Jackett.Common/Indexers/Definitions/`. If the tag you use no longer has `PublicBrazilianIndexerBase.cs` (it lives under `Indexers/Definitions/Abstract/` in recent versions), copy it from this repository as well.
2. Compile (replace `0.24.2830` with your version, without the `v`):

```
dotnet publish src/Jackett.Server/Jackett.Server.csproj -c Release -f net9.0 -r linux-x64 --self-contained false -o out /p:Version=0.24.2830 /p:AssemblyVersion=0.24.2830 /p:FileVersion=0.24.2830 /p:InformationalVersion=0.24.2830
```

3. Take `out/Jackett.Common.dll` and use it as in the Docker example. If upstream changed `PublicBrazilianIndexerBase.cs` or `HDRTorrent.cs` in the version you use, compare them with the ones in this repository before building. The three files may need adjustment.

## Tests behind each release

Before a release, the patched DLL runs in an isolated container with a copy of a real configuration, and the three indexers must pass the connection test and return results for `matrix` and `vingadores`. The sites can change their layout at any time, and then the indexers will break until the parsers are updated.

## About AI assistance

These changes were developed with the help of an AI assistant (Claude) and tested by the maintainer of this fork against the live sites. The upstream Jackett pull request template does not accept pull requests that are predominantly generated by AI, so the changes are published here instead of as a pull request. Anyone from the Jackett project is welcome to take the code as a reference.
